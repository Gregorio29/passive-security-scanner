# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please report it responsibly:

1. **Do not create a public issue.**
2. Send vulnerability details and proof-of-concept privately to the project maintainers via GitHub Security Advisories or direct private communication.
3. Include detailed steps to reproduce the behavior.
4. Maintainers will review the report within 48 hours and coordinate a security fix.

## Non-Intrusive Scanning Notice
This tool is designed strictly for defensive posture evaluation, authorized auditing, and educational use. It must not be used against targets without prior authorization.
